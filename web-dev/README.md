# 🌐 Bhanu Saini | Web Developer Portfolio

> Portfolio showcasing modern web development projects using React, TypeScript, and cutting-edge technologies.

## 🌟 Deploy This

This folder is designed to be deployed as a **standalone website**. Simply deploy the contents to any static hosting service like:

- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, TypeScript, React, Next.js
- **Styling:** TailwindCSS, GSAP Animations, CSS3
- **3D/Graphics:** Three.js
- **Backend:** Node.js, Flask
